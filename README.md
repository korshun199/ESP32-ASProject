# ESP32 Acoustic Radar

Акустический радар на ESP32 с двумя каналами I²S.

Цель проекта — определять направление на источник звука по разнице сигналов двух микрофонных каналов.

## Возможности

- Анализ частот 400, 1000 и 2000 Гц.
- Обучение по фоновому шуму.
- Фиксация усиления перед измерением.
- Круговое измерение на 360 градусов.
- Сравнительное измерение от 0 до 180 градусов.
- Запись результатов через последовательный порт.

## Файлы

- firmware/radar.ino — рабочая прошивка ESP32.
- firmware/install.sh — установка и загрузка прошивки.
- scripts/scan360.py — круговое измерение.
- scripts/scan180.py — измерение от 0 до 180 градусов.

## Установка прошивки

Команда:

    ./firmware/install.sh

## Круговое измерение

Команда:

    python3 scripts/scan360.py

## Измерение 0–180 градусов

Команда:

    python3 scripts/scan180.py

## Параметры подключения

- Последовательный порт: /dev/ttyACM0
- Скорость: 115200 бод
- Расстояние до источника: 2 метра
- Нулевая отметка: трубка направлена на источник
- Плоскость вращения: горизонтальная
