# ESP32 Audio Radar

Универсальная система наблюдения и анализа звука на базе ESP32-S3, цифрового микрофона ICS-43434 и веб-интерфейса реального времени.

Проект принимает звук через I2S, рассчитывает основные параметры сигнала, формирует осциллограмму и спектр, затем передаёт данные через последовательный порт в Python-сервер и браузер.

## Текущая контрольная точка

Рабочая версия зафиксирована коммитом:

`3b152ec Add live configurable audio radar dashboard`

Реализовано:

- чтение цифрового микрофона ICS-43434 через I2S;
- частота дискретизации 16 кГц;
- окно анализа 512 отсчётов;
- расчёт RMS, Peak, P2P, Mean, Min и Max;
- осциллограмма из 64 точек;
- спектр из 32 полос;
- диапазон спектра от 125 до 7875 Гц;
- вывод диагностических данных через Serial;
- отображение основных параметров на TFT ST7789;
- Python-сервер для чтения Serial;
- передача данных в браузер через WebSocket;
- живая история громкости;
- осциллограмма;
- спектр;
- бегущая спектрограмма;
- ручная настройка масштабов и сглаживания;
- сохранение настроек в браузере.

## Архитектура

`ICS-43434 -> ESP32-S3 -> Serial -> Python -> WebSocket -> браузер`

ESP32 выполняет сбор и первичный анализ звука.

Python-сервер:

- открывает последовательный порт;
- разбирает пакеты `FRAME`, `WAVE` и `SPECTRUM`;
- объединяет их в один JSON-кадр;
- передаёт кадры подключённым браузерам.

Браузер выполняет визуализацию и пользовательское масштабирование данных.

## Оборудование

### ESP32

Используется плата:

- ESP32-S3 N16R8;
- Flash 16 МБ;
- PSRAM 8 МБ.

### Микрофон ICS-43434

Подключение:

| ICS-43434 | ESP32-S3 |
|---|---|
| SCK / BCLK | GPIO4 |
| WS / LRCLK | GPIO5 |
| SD / DATA | GPIO6 |
| L/R | GND |
| VDD | 3.3V |
| GND | GND |

Канал микрофона используется левый.

### TFT ST7789

Подключение:

| ST7789 | ESP32-S3 |
|---|---|
| CS | GPIO10 |
| DC | GPIO9 |
| RST | GPIO8 |
| MOSI | GPIO11 |
| SCLK | GPIO12 |
| VCC | 3.3V |
| GND | GND |

Разрешение дисплея:

`240x320`

## Прошивка ESP32

Подключить плату и выполнить:

`./scripts/run.sh`

Последовательный порт по умолчанию:

`/dev/ttyACM0`

Скорость:

`115200`

Для просмотра потока вручную:

`arduino-cli monitor -p /dev/ttyACM0 -c baudrate=115200 -c dtr=off -c rts=off`

## Запуск веб-панели

Сначала закрыть все программы, использующие `/dev/ttyACM0`.

Затем выполнить:

`./scripts/web_live`

Скрипт:

- создаёт виртуальное окружение `web/.venv`;
- устанавливает зависимости;
- открывает `/dev/ttyACM0`;
- запускает сервер на порту 8080.

Открыть в браузере:

`http://127.0.0.1:8080`

## Формат данных Serial

ESP32 передаёт три строки на один кадр:

`FRAME`

Основные измерения и диагностика.

`WAVE`

Нормализованная осциллограмма.

`SPECTRUM`

Значения 32 частотных полос.

Пакет завершается строкой:

`---`

Python-сервер объединяет строки по метке `T_MS`.

## Диагностика

Проверка состояния сервера:

`http://127.0.0.1:8080/health`

Последний принятый кадр:

`http://127.0.0.1:8080/api/latest`

Нормальная работа:

- `serial_connected: true`;
- `READ_ERR=0`;
- ESP32 FPS около 23–25;
- графики обновляются без разрывов;
- WebSocket автоматически переподключается после обновления страницы.
