# Первый реальный микрофон радара

## Контрольная точка

Дата этапа: 04 июля 2026.

Собран и проверен первый реальный акустический канал радара.

Рабочая цепочка:

    направленный микрофон
      -> усилитель
      -> ограничение сигнала
      -> ESP32 GPIO34 / D34
      -> USB Serial
      -> scripts/radar_serial_mic_bridge.py
      -> POST /api/esp32/push
      -> web/radar_virtual_mics/server.py
      -> control.html, режим ESP32 buffer

## Подключение

Микрофонный усилитель питается от 9 В.

Общая земля обязательна:

    GND питания 9 В
    GND усилителя микрофона
    GND ESP32

Сигнал микрофона подключён так:

    OUT микрофонного усилителя -> ограничение/защита -> D34 / GPIO34 ESP32

GPIO34 используется как аналоговый вход ADC1.

## Почему пока один микрофон

С одним микрофоном направление определить честно нельзя.

На текущем этапе проверяется полный тракт:

    реальный звук -> ESP32 -> USB -> сервер -> веб-радар

В интерфейсе MIC1 временно считается верхним сектором.

## План на четыре микрофона

Рекомендуемая раскладка:

    MIC1 ВЕРХ   -> GPIO34 / ADC1
    MIC2 ПРАВО  -> GPIO35 / ADC1
    MIC3 НИЗ    -> GPIO32 / ADC1
    MIC4 ЛЕВО   -> GPIO33 / ADC1

Используем ADC1-пины, чтобы в дальнейшем Wi-Fi не конфликтовал с измерением аналоговых входов.

## Что смотреть в выводе bridge

Главные параметры:

    raw  - последнее значение ADC
    p2p  - размах min/max за окно измерения
    vol  - нормированная громкость 0.0..1.0

Нормальная диагностика:

    тишина         -> p2p небольшой
    звук в трубку -> p2p и vol растут
    перегруз      -> min около 0 или max около 4095
