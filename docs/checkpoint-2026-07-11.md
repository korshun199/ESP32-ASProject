# ESP32 Radar — контрольная точка 11.07.2026

## Аппаратная часть

- ESP32-S3 N16R8
- TFT ST7789
- цифровой микрофон ICS-43434
- serial-порт: `/dev/ttyACM0`
- скорость serial: `115200`

## Основная прошивка

    firmware/radar/radar.ino

Прошивка:

- читает ICS-43434 через I2S;
- выводит информацию на TFT;
- формирует диагностические кадры;
- выводит короткие фрагменты формы волны.

Формат кадра:

    FRAME=... count=... mean=... level=... p2p=... zc=... f400=... f1000=... tone=...
    WAVE_K=...

## Инструменты

### scripts/analise_tone

Разбирает лог на отдельные периоды и массивы кадров.

Показывает:

- FRAME;
- count;
- mean;
- level;
- p2p;
- zc;
- f400;
- f1000;
- tone;
- WAVE_K.

### scripts/get_tone

Записывает три диагностических периода в:

    /tmp/000.log

Заголовок периода:

    <<время,частота,громкость>>

### scripts/record_sync

Одновременно записывает:

    web/data/000.log
    web/data/000.wav

Пример:

    ./scripts/record_sync 30 400 30

Аргументы:

    ./scripts/record_sync ВРЕМЯ ЧАСТОТА ГРОМКОСТЬ

Каждая строка serial-лога получает метку времени:

    T_MS=1250.438 FRAME=...
    T_MS=1251.102 WAVE_K=...

WAV записывается через ALSA с микрофона компьютера.

Исправлено: `arecord` запускается без параметра `-d`, потому что он не принимает дробную длительность вроде `30.0`. Процесс останавливает сам Python-скрипт.

## Веб-панель

Файл:

    web/index.html

Возможности:

- загрузка диагностического лога;
- отдельный график каждого параметра FRAME;
- график WAVE_K;
- выбор периода;
- бегущая синхронная временная линия;
- старт, пауза и перемотка;
- воспроизведение WAV вместе с графиками;
- работа без CDN и внешних JavaScript-библиотек.

Запуск:

    python3 -m http.server 8080 --directory web

Открытие:

    http://127.0.0.1:8080/index.html

## Ограничение

Данные ESP32 снимаются с ICS-43434, а WAV сейчас записывается микрофоном компьютера. Возможен небольшой постоянный временной сдвиг.

Для проверки синхронизации можно сделать короткий хлопок сразу после старта записи.

Для получения настоящего WAV непосредственно с ICS-43434 потребуется отдельная передача непрерывного PCM-потока с ESP32.
